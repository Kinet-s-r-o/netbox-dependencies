What registering does

A poller works without being registered — it appears on the page as auto-detected and uses the shared settings. Registering it lets you:

  • describe it and switch it off from NetBox,
  • give it a scope: it then pings only the devices of the chosen sites, and every other poller skips those sites (one poller per network, no duplicate pings),
  • override the interval, packets, timeout or concurrency for just this poller.

NetBox does not start the container. Run it with POLLER_NAME set to the name above (see examples/docker-compose.poller.yml) and give each poller its own name.
