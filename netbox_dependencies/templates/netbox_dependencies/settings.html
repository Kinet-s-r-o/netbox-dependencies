How it works

One message per root-cause outage (not per affected device) when it starts, and one when it ends. Every destination gets its own copy; if one fails, only that one is retried.

  • Teams: Workflow When a Teams webhook request is received → Post card in a chat or channel, card = triggerBody()?['card']. Paste the Workflow URL.
  • Slack: create an Incoming Webhook for the channel (Slack app → Incoming Webhooks) and paste its URL.
  • Generic webhook: any HTTP endpoint that accepts JSON (event: outage / recovery, with the devices and impact). Optional signing secret → header X-Signature-256.
